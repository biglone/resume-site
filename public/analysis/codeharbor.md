## 06. 源码/项目深读

## 项目难点
Matrix 房间消息天然是异步的，而 CLI 任务可能运行数分钟并产生附件、进度和交互式输出，因此需要把“消息回复”提升为可恢复的任务状态机。

## 架构
Matrix Room → Channel Adapter → Orchestrator → AI CLI Executor
                                ↓
                            SQLite StateStore

## 我的贡献与技术亮点
- 用 SQLite 持久化房间、用户、任务和 AI 会话映射，使机器人重启后可以继续识别上下文。
- 用限流、并发闸门、取消机制和逻辑 worker 控制长时间 CLI 任务，并增加重复 Matrix 事件防护，避免一个房间或重复事件拖垮整个网关。
- 抽象图片、语音、生成文件和进度消息适配，增加本地 Whisper/OpenAI 转写回退、文件投递意图和 request_id 级可观测性。
- 维护 TypeScript 主运行时与 Python legacy 兼容边界，配合 Vitest、Playwright、typecheck、lint、覆盖率检查和 NPM release 流程交付。
