## 06. 源码/项目深读

## 项目难点
桌面 UI、串口设备和音频输出都有独立生命周期，启动顺序、设备热插拔和部分写入失败会直接影响演示现场的稳定性。

## 我的工作
- 设计 Electron 主进程、Preload 和 React UI 的通信边界，避免渲染层直接持有设备权限。
- 实现自定义串口协议、CRC16 校验、忙碌重试、连接启动门控和状态回传；将“设备未就绪”变成可解释的 UI 状态，而不是静默失败。
- 实现角度跟踪、手动角度、8 通道增益、输出设备切换和 Web Audio 可视化，并兼顾 Windows/macOS/Linux 打包差异。
