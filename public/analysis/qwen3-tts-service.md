## 06. 源码/项目深读

## 项目定位
Qwen3-TTS Service 把本地大模型语音能力封装成 HTTP 服务，面向 Jetson GPU 环境提供定制音色、文本驱动声音设计和参考音频克隆。

## 技术深挖
- 通过 FastAPI 统一 `/v1/tts/custom`、`/design` 和 `/clone` 接口，分别覆盖内置音色、提示词设计和参考音频克隆。
- 同时支持同步输出、chunked streaming 和 SSE 分段音频，返回 wav/mp3，便于桌面端、设备端和 Web 端接入。
- Docker 使用 NVIDIA runtime、模型目录只读挂载和 HuggingFace 缓存，解决 GPU 运行时、模型体积和重复下载问题。
- 通过 `/healthz`、`/v1/voices` 和 `/v1/models` 提供部署探针和能力发现，为后续接入设备服务保留稳定边界。

## 面试切入点
