## 01. 结论先行

**项目定位**：支持历史记录、周期任务、番茄钟和多账号隔离的自托管待办事项平台。

这个项目的工程主线可以概括为：**Web产品与数据服务**。面试时应优先讲清业务目标、关键边界、个人负责模块，以及设计如何降低实时性、稳定性、兼容性或交付风险。

### 适合展示的项目信号

- 使用 Node.js、Express 和 SQLite 实现账号隔离、任务持久化和层级任务管理。
- 支持周期任务自动生成、服务端分页、批量编辑、导入导出和多步撤销。
- 通过 Docker、Cloudflare Tunnel、自动化测试和 CI 构建完整交付链路。

## 06. 源码/项目深读

## 项目定位
Todo Harbor 是一个面向个人和小团队的自托管待办与专注管理平台。

## 技术难点与我的贡献
- 使用 SQLite 持久化账号、任务、番茄钟和操作历史，并在服务端按账号隔离数据。
- 将父子任务、项目/标签、到期日、优先级、周期任务、批量编辑和服务端分页组织为同一套任务模型。
- 实现每日/每周/月度周期任务生成、JSON 导入导出、多步撤销和提醒，重点处理重复操作与历史状态恢复。
- 通过 Docker、Cloudflare Tunnel、lint/test 和 CI 形成自托管部署闭环。
