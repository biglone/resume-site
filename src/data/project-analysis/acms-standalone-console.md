## 06. 源码/项目深读

## 项目定位
ACMS 独立部署控制台直接服务于声像仪现场操作，覆盖设备通用配置、校准、预览/回放、PTZ 云台和系统升级维护。

## 技术难点与我的工作
- 按配置、预览、回放和维护拆分 React 页面，通过 OpenAPI 请求层连接设备服务。
- 参与 PTZ 实时角度同步、巡检点配置和云台控制；部分配置请求需要组合多个 MQTT 语义，同时保证设备返回状态及时刷新。
- 参与校准模式进入、设备时间/网络/存储配置和升级倒计时，处理接口成功但设备状态尚未同步时的 UI 一致性。
- 配合多语言资源、版本化构建和独立部署配置支持现场安装与维护。
