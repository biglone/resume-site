## 06. 源码/项目深读

## 项目定位
该项目是一套面向 Lenovo 音频设备的 Windows 控制软件，UI 侧负责设备模式、EQ 和音频效果配置，底层通过 C++ DLL、RPC/IPC 与设备能力连接。

## 我的工作与技术亮点
- 参与 WPF 控制台和 C++ 设备模块的协作，处理麦克风、雷达、扬声器设备以及本地配置之间的状态同步。
- 实现 EQ 模式、增益值、会议模式和播放效果配置，针对设备连接状态决定控件是否可用，并对连续 EQ 命令增加 100ms 间隔限制。
- 参与管道数据使用 MessagePack 序列化和 Base64 编码传输，减少跨进程传输中的结构歧义。
- 通过设置持久化、成功提示和日志补齐现场可见反馈，避免“配置提交成功但设备状态未知”的问题。

## 可展开的工程问题
重点可以从 WPF UI 与 C++ 设备层边界、RPC/IPC 数据模型、设备断连后的状态恢复，以及频繁命令对硬件控制的节流策略展开。
