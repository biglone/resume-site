## 06. 源码/项目深读

## 项目定位
这是一个把 AI 原理学习转化为工程实验的项目集合，既包含 C++ 推理优化，也包含面向真实代码库的 RAG 问答系统和完整的理论/部署文档。

## 技术深挖
- C++ 推理引擎围绕 KV Cache、INT8 量化和 AVX2 SIMD 做性能实验，重点理解首 token 延迟、内存占用和精度之间的关系；仓库记录了约 30 倍首 token 加速和 75% 内存节省的实验目标。
- RAG 系统使用 tree-sitter 保持函数/类结构完整，再结合 OpenAI embedding、ChromaDB、混合搜索和 MMR 重排，为多语言代码提供来源可追溯的问答。
- 通过 Gradio、benchmark、单元测试和 Docker 模板把理论验证落成可运行工程，而不是只停留在笔记或 Prompt 示例。

## 面试切入点
可以展开 KV Cache 的复杂度变化、量化带来的精度/内存取舍、代码语义分块为什么优于固定长度切块，以及 RAG 答案如何返回来源证据。
