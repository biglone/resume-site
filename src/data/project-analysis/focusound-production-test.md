## 01. 结论先行

**项目定位**：面向聚音屏量产测试的 Windows 自动化平台，统一控制测试仪器、治具板和功放板并完成声学判定。

这个项目的工程主线可以概括为：**桌面端设备工作台**。面试时应优先讲清业务目标、关键边界、个人负责模块，以及设计如何降低实时性、稳定性、兼容性或交付风险。

### 适合展示的项目信号

- 通过串口、VISA.NET 和 Audiobus API 控制 LCR 测试仪、示波器和音频分析仪。
- 将设备发现、连接监测、测试调度、参数采集和结果判定拆分为独立库。
- 支持三语言、Velopack 自动更新、release/beta 渠道和设备库单元测试。

### 公开可核对指标

- **测试对象**：聚音屏全通道
- **仪器接入**：LCR / 示波器 / 音频分析仪
- **交付能力**：自动更新 + 多语言

## 06. 源码/项目深读

## 项目定位
为聚音屏生产测试提供统一工作台，依次完成设备连接、通道切换、F0/LCR、电压/功率和声学指标测试，并对功放板参数和固件进行管理。

## 技术难点与我的工作
- 将串口、VISA.NET、Audiobus 和治具/功放板协议隔离到独立设备控制库，再由 WPF 主程序统一编排测试步骤。
- 通过设备发现、连接监测、测试调度和测量服务降低现场手工切换仪器造成的漏测风险；串口数据流接口支持 Mock，便于单元测试。
- 兼容 .NET Framework 与 .NET Standard 2.0 设备库边界，满足测试平台和外部上位机复用同一套设备控制能力。
- 维护 Velopack 自动更新、中文/繁体中文/英文资源及 release/beta 发布脚本，支撑产线持续升级。
