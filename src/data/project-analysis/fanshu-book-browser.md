## 06. 源码/项目深读

## 项目定位
帆书分类图书浏览站是一个本地内容整理和浏览产品，重点不在复杂后端，而在于把大量分类、书目信息、作者、摘要、荐语和摘录组织成清晰、可检索、适合长时间浏览的界面。

## 技术深挖
- 使用 React + Vite，数据内置为本地 JSON，页面加载后不依赖实时接口，降低部署和网络波动对浏览体验的影响。
- 在同一数据模型上实现业务线切换、分类筛选、书名/作者/摘要搜索和详情信息展开，保持搜索与浏览状态一致。
- 设计 refined、playful、brand 三套主题，通过 CSS 变量和组件样式组织视觉差异，验证内容产品在信息密度、可读性和风格之间的取舍。
- 配套截图、构建、lint 和免责声明，体现从数据整理到可发布前端产品的完整闭环。

## 面试切入点
可以从本地数据与实时 API 的取舍、搜索字段归一化、主题 token 设计，以及高信息密度页面如何保持阅读层次展开。
