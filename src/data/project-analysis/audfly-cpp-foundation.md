## 06. 源码/项目深读

## 项目定位
多个音频采集、处理和设备项目都需要稳定的生产者/消费者队列、环形缓冲和计时能力，因此将高频并发基础设施沉淀为独立 C++ 库。

## 技术难点与我的工作
- 改进 `shared_queue::pop_front`，使队列为空时等待，并在有数据或停止条件满足时返回确定结果，避免业务侧重复编写等待逻辑。
- 通过互斥量和条件变量支撑多线程生产/消费，配合环形队列的容量限制处理满载、空载和边界数据。
- 将组件设计为 CMake/vcpkg 可复用包，同时维护 Visual Studio 工程、GoogleTest 测试、lint 和 CI 脚本。
