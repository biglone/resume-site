## 06. 源码/项目深读

## 项目定位
Linux.do Scout 面向 Discourse 论坛内容建立本地抓取和搜索能力，用低依赖的 Node.js + SQLite 方案把“定期获取、结构化保存、快速检索”串起来。

## 技术深挖
- CLI 提供 `crawl` 和 `search` 两类入口，抓取逻辑、数据库访问和 Web UI 分层，既能脚本化运行，也能浏览结果。
- 使用 better-sqlite3 持久化论坛内容，针对本地工具优先低运维成本和可迁移性，而不是引入重量级服务端数据库。
- 通过 TypeScript、npm build、ESLint、Dockerfile 和 compose 文件形成可安装、可运行、可发布的工具链。

## 面试切入点
可以从增量抓取的幂等性、SQLite 查询索引、外部站点限流/失败重试，以及 CLI 与 Web UI 复用同一数据层展开。
